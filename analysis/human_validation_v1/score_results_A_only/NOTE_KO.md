# 주의: 평가자 한 명(A)만의 결과 (2026-10-14)

- 돌아온 파일 두 개(`returned/`) 가운데 B는 A와 판정·질문 2 답·메모까지 300개 모두 같은 복사본이었다. 사용자는 "A만 써. 사람이 판정한 거니까"라고 했다(2026-10-14).
- 그래서 `score.py`를 A 파일을 두 번 넣어 돌렸다. 코드는 바꾸지 않았다.
  - `score_summary_KO.md` 1절(두 사람 사이 일치도 κ = 1.000)과 질문 2 보고서 1절은 **의미가 없다**. 같은 파일을 비교한 값이다. 논문에 쓰지 않는다.
  - "사람 합의", "A_only", "B_only"는 모두 평가자 A 한 명의 라벨이다.
- 논문에는 "평가자 한 명(제1저자)이 조건과 자동 판정 라벨을 모르는 상태에서 300개 항목을 판정했다"고 쓴다. 두 사람 사이 신뢰도는 보고할 수 없다.
- 파일 정보(docProps)의 마지막 수정자가 openpyxl이고 수정 시각이 묶음 생성 시각 그대로라, 엑셀이 아닌 프로그램으로 저장된 파일이다. 사용자 진술에 따라 사람 판정으로 취급한다.
