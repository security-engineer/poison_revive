## 해석(등록한 규칙대로)

- 등록 문장: "실제 서버에서 오류 뒤 실제 피해가 늘어나는 현상이 새 모델 3개에서도 되풀이되었다."
- 반드시 함께 쓸 것:
  1. 새 모델 쪽 신호는 거의 Qwen3-30B 한 모델에서 나왔다(12:2). Gemma는 같은 방향이지만 작고(2:0), gpt-oss-120b는 짝이 4개라 판단할 수 없다.
  2. 패밀리 묶음 검정(7:2, p = .18)과 Git::11–13을 뺀 민감도(9:2, p = .065)는 새 모델만으로는 확인되지 않았다. 다섯 에이전트를 합치면 둘 다 확인된다.
  3. 오류 없이 생긴 실제 피해 3건은 모두 읽기 전용 첫 호출 뒤 작업을 이어 가다 생겼다.
  4. FileSystem 보조 분석은 두 모델 모두 효과가 거의 없었다(1:0, 0:0).
- Qwen3-30B는 결과 메시지 교체 실험의 작업 계속 대조(v5 H7)에서 확인되지 않았던 모델인데, 실제 Git 서버에서는 가장 강했다. 결과 메시지 교체 실험은 두 번째 응답 하나만 보지만, 실제 서버 실험은 최대 4단계를 보므로 "오염된 도구를 한 번 부르고 나서 따르는" 이 모델의 흐름을 잡는다. 이 차이는 사후 관찰이며 검정하지 않았다.
